# pallaviraiturkar0.github.io

Personal website and portfolio for Pallavi Raiturkar.

## Local preview

No build step is required. Serve the repository root with any static file server:

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Deployment

The site is designed for GitHub Pages and deploys from the root of the `main` branch at [pallaviraiturkar0.github.io](https://pallaviraiturkar0.github.io).

## Editing

- Page content, styles, and scripts: `index.html` (single self-contained file)
- Studio artwork: `art/` (WebP, 1200x1500); pixel portrait source: `pallavi-pixel.png`
- Product and design context: `PRODUCT.md` and `DESIGN.md`
